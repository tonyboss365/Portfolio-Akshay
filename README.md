# Akshay Kumar Reddy — Portfolio

This repository contains the source for my personal portfolio site built with Vite + React + TypeScript.

## About this portfolio

This portfolio showcases projects, skills, and a brief write-up of my experience. The site is responsive, theme-aware, and optimized for fast loading using Vite.

![Flowchart](public/images/flowchart.svg)

## Structure

- `src/` — React + TypeScript source files
- `public/` — static assets (images, icons)
- `index.html`, `vite.config.ts`, `tsconfig.json` — build configuration

## How to run locally

Install dependencies and run the dev server:

```bash
npm install
npm run dev
```
